# Shadow Assassin

An original top-down 2D stealth assassin game for Android, built with
Godot 4.3. Sneak through 10 colourful levels, stay out of the guards'
vision cones, and take every guard out from behind.

> **Original game.** The name, art, code, levels and characters were all
> made from scratch for this project. The genre (top-down stealth) is the
> only inspiration — no assets, sprites, levels or code were copied from
> any other game.

## How to play

- **Tap a floor tile** to move there.
- **Tap a guard** to sneak up behind them and take them out.
- **Stay out of the yellow vision cones.** If a guard spots you, they
  chase you — break line of sight behind walls and crates until they
  give up and go back to patrol.
- **Grab coins and gems** for extra stars.
- **Eliminate every guard** to clear the level.
- **Stars:** 1 for clearing the level, +1 for collecting everything,
  +1 for never getting spotted.

## Download the APK

Every push to `main` builds a debug APK and publishes it to the
**latest** release — no GitHub login needed to download:

https://github.com/musehiro/shadow-assassin/releases/download/latest/ShadowAssassin-debug.apk

Install it on Android (allow "Install unknown apps" for your browser
when asked). The game is a debug build for testing; the Play Store
release build comes later from the Play Console.

## Build it yourself

Requires Godot 4.3.

```sh
# Open the project in the Godot editor, or run it headless:
godot --headless res://scenes/main.tscn

# Android export (needs the Android export templates + SDK):
godot --headless --export-debug "Android" build/ShadowAssassin-debug.apk
```

The GitHub Actions workflow (`.github/workflows/android.yml`) does the
same build in CI using the `barichello/godot-ci:4.3` image.

## Project layout

```
project.godot            Godot project (720x1280 portrait, GL Compatibility)
scenes/main.tscn         Root scene
scripts/
  main.gd                Main menu, level select, screen switching
  game.gd                Game controller: board, input, HUD, win/lose
  player.gd              The shadow assassin (tap-to-move + hunt)
  guard.gd               Patrolling guard with vision cone + chase AI
  levels.gd              10 original level definitions + validator
  save_data.gd           Progress save (unlocked levels, stars, coins)
  sfx.gd                 Sound-effect player
art/                     Original sprites (drawn with PIL, see tools/)
audio/                   Original synthesized sound effects (see tools/)
tools/
  make_art.py            Regenerates every sprite from scratch
  make_sfx.py            Regenerates every sound from scratch
  gen_levels.py          Generates levels 11-50 (seeded, solvability-checked)
tests/
  smoke_test.gd          Headless smoke test (coin, hunt, win)
  validate_levels.gd     Headless check: 50 levels, all checks, level 50 runs
```

Art and sounds are generated by the scripts in `tools/` — run them to
regenerate everything from scratch.

## Levels

**50 levels in v1.** The first 10 are hand-designed (an easy on-ramp);
levels 11–50 are generated by `tools/gen_levels.py` from deterministic
seeds across five layout archetypes (Hall, Corridors, Maze, Crossroads,
Ring). Difficulty rises a little every level:

| Levels | Guards | Patrol speed | Vision cone | Coins | Gems |
|--------|--------|--------------|-------------|-------|------|
| 1–10 (hand-made) | 1–6 | 1.1–1.9 t/s | 3.67 tiles / 45° | 4–12 | 0–4 |
| 11–20 | 6–7 | 1.7–1.8 t/s | 3.5–3.8 tiles / 45–47° | 12–13 | 3–4 |
| 21–30 | 7 | 1.8–1.9 t/s | 3.8–4.0 tiles / 48–50° | 13–14 | 4 |
| 31–40 | 8 | 1.9–2.0 t/s | 4.1–4.3 tiles / 50–52° | 14–15 | 4–5 |
| 41–50 | 8–9 | 2.0–2.1 t/s | 4.4–4.6 tiles / 53–55° | 15–16 | 5 |

Every level is beatable — each one is checked before it ships:

1. **Reachability** — every coin, gem and guard patrol waypoint is
   reachable from the player start (BFS).
2. **Approach window** — every guard has at least one patrol waypoint
   where a walkable tile next to the patrol is outside *every* guard's
   vision cone, so there is always a timing window to strike from
   behind.
3. **Clean start** — the player never starts inside a vision cone.

The checks live in `ShadowLevels.validate()` (run headless with
`godot --headless -s res://tests/validate_levels.gd`) and are mirrored
in `tools/gen_levels.py`, which regenerates any level that fails.
Later levels are hard — they need real timing and route planning —
but never impossible.
